## 从 GitHub 获取并运行

```powershell
git clone https://github.com/xueReact/hetero-ops-platform.git
cd hetero-ops-platform
docker compose up -d --build platform
Start-Process http://localhost:8001/airport-console
```

如果本机已有机场服务在 `8094`，平台会通过 `AIRPORT_UPSTREAM` 连接它：

```powershell
$env:AIRPORT_UPSTREAM = 'http://host.docker.internal:8094'
docker compose up -d --build platform
```

第一次完整启动机场场景：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start-windows.ps1 -Standalone
```

## 运行检查

```powershell
Invoke-RestMethod http://localhost:8001/api/health
Invoke-RestMethod http://localhost:8001/airport-runtime/api/status
docker compose ps
```

页面入口：

- `http://localhost:8001`：Fire 平台总览。
- `http://localhost:8001/airport-console`：机场实时控制台。
- `http://localhost:8001/airport-console/view/`：机场控制台独立视图。

## 停止

```powershell
docker compose --profile airport stop
```

## 说明

机场运行依赖 Docker Linux containers、ROS 2 Humble、Gazebo 和 Open-RMF；建议 Docker 至少分配 8 GB 内存。GitHub Pages 只能托管静态页面，不能启动本项目的实时调度器和三维仿真后端。

机场地图和模型来源、第三方许可证见 `simulations/airport-upgrade/THIRD_PARTY_NOTICES.md`。机场数据为仿真场景，实体设备接入需要另行实现驱动适配器。
